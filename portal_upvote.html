Step 2 of 2 — Make it survive restarts

Copy the value below and add it as UPVOTE_SESSION_B64 in your Railway service → Variables. The agent will restore the session automatically on every restart. Valid for 30 days — repeat after re-authorizing.

Open Railway
Mainnet note The Abstract Session Key Policy Registry requires a security review before session keys can call contracts on mainnet. If the upvote contract (0x3b50de27…ce2a) is not yet whitelisted, the daily upvote will revert silently. Everything else (session creation, storage) still works.
How it works
  1. Click Connect Abstract Global Wallet — the Abstract wallet popup opens.
  2. Sign in with your AGW. A scoped session key is created automatically.
  3. Add UPVOTE_SESSION_B64 to Railway so the session survives restarts.
  4. The agent upvotes the next Portal app daily at 09:00 UTC.
